# 📝 To-Do List

A simple and clean to-do list web app built using **HTML, CSS, and JavaScript**. It has a warm notebook-style design and saves your tasks in the browser, so they are still there after you refresh or close the page.

## Features

- Add new tasks (click **Add** or press **Enter**)
- Mark tasks as done or not done by clicking on them
- Delete tasks with the ✕ button
- Shows how many tasks are left
- Tasks are saved using **localStorage**
- Responsive, simple layout with a custom color theme

## Technologies Used

- **HTML5** for structure
- **CSS3** for styling (flexbox, custom colors, box-shadow)
- **JavaScript (ES6)** for logic and DOM manipulation
- **localStorage** for saving data in the browser

## How to Run

1. Clone the repository:
   ```
   git clone https://github.com/your-username/todo-list.git
   ```
2. Open the project folder.
3. Open `todo.html` in your browser (or use the **Live Server** extension in VS Code).
